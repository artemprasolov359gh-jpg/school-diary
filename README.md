# Школьный дневник — повторяющееся недельное расписание

## Что изменилось
- Расписание задаётся один раз по дням недели (понедельник–воскресенье) и повторяется каждую неделю.
- Уроки можно добавлять, редактировать и удалять в админ-панели.
- Домашние задания задаются отдельно на конкретную дату и не повторяются.
- В ученическом приложении увеличены карточки, шрифты, даты и отступы; выбранный день недели подписан.
- Данные синхронизируются через Firebase Firestore.

## Обновление Firebase
1. Откройте `admin/firebase.js` и `student/firebase.js`.
2. Вставьте один и тот же актуальный `firebaseConfig` из Firebase Console.
3. В Firebase Console → Firestore Database → Rules опубликуйте правила из `firestore.rules`, заменив `PASTE_ADMIN_UID_HERE` на UID администратора (один раз).
4. Старые записи из коллекции `lessons` новая версия не показывает. Новое расписание хранится в `weeklySchedule`, домашние задания — в `homework`.

## Публикация
Загрузите содержимое папки проекта в корень существующего GitHub-репозитория, заменив старые файлы и папки `admin` и `student`. В GitHub Pages оставьте `main` и `/ (root)`.
- Админ: `/admin/`
- Дневник ученика: `/student/`

## Важно
Коллекции доступны для чтения всем посетителям сайта, поэтому не добавляйте в расписание персональные данные учеников. Правила ограничивают запись UID администратора.
